## 1. Executive Summary of Live Preview State (`jiyuiydzsfydjklosvvq`)

Live inspection of `jiyuiydzsfydjklosvvq` confirmed:
- **Tables Present:** **23 / 23 tables** exist in `public` (all 18 Production core tables + all 5 Preview feature tables: `system_settings`, `customer_email_outbox`, `payment_recovery_tokens`, `payment_screenshots`, and `order_collaboration_notes`).
- **RPC Functions Present:** **22 / 22 exposed RPC routines** (plus 5 trigger functions = 27 total functions).
- **Storage Buckets Present:** **2 / 2 private buckets** (`payment-screenshots` and `seller-payment-qrs`, both `public = false`, `2 MB` max size, `image/jpeg`, `image/png`, `image/webp`).
- **Actionable Divergences Identified Between Production & Preview:**
  1. **`anon` RLS Function Grant (`public.is_staff`):** Querying `public.campaigns` or `public.prizes` with the `anon` publishable key returns `42501: permission denied for function is_staff` because `EXECUTE ON FUNCTION public.is_staff(uuid)` was revoked from `anon` in `202610300001_p0_security_remediation.sql` while `campaigns_public_read` and `prizes_public_read` invoke `public.is_staff(auth.uid())`.
  2. **Seller Configuration & Unsanitized Personal UPI in Preview:**
     - Production has `SELLER-007` (`Dehradun`) and `SELLER-003` (`Delhi`).
     - Preview had `SELLER-003` named `Graphic Era` (`is_qr_active = false`), `SELLER-002` named `Delhi` (`is_qr_active = false`), and `SELLER-008` (`GEU`) containing a **real personal UPI ID (`8810366357@ptyes`)** and non-watermarked QR image.
  3. **Unsanitized Customer PII & Missing Watermarked Screenshots in Preview:**
     - Preview `customers` (52 rows) and `tickets` (36 rows) contained unmasked emails (`gmail.com`, `outlook.com`, `beacon.ac.in`, `geu.ac.in`) and real phone numbers instead of sanitized `@preview-test.invalid` emails and `90000XXXXX` test phone numbers.
     - 23 `SUBMITTED` / `VERIFIED` payments in Preview lacked `payment_screenshots` rows, and existing screenshot objects were not watermarked `[PREVIEW TEST]` evidence.
